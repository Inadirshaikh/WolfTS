# WolfTS

Legal Tatkal helper (demo) — user-assisted starter project.

This repository is a demo and does NOT perform any automated bookings or bypass any external sites. It provides local templates, a mock booking page, reminders, and a dashboard for testing and analysis only.

Quick start (requires Node 18+):

1) Backend:
   cd backend
   npm install
   npm start

2) Frontend:
   cd frontend
   npm install
   npm run dev

Project purpose:
- Demonstrates templates, reminders, dashboard and client-side autofill of a mock booking form.
- NOT for automating any real IRCTC flows.
